# 頭の 3D モデルから VRM を作る（face-maker）

ユーザーへの文章はすべて日本語で書く。手順の本体は `make_face.sh`。説明は `README.md`。

## 0. 始める前
1. `./check.sh` を通す。NG があれば、表示された直し方をユーザーに伝える（Blender・MPFB・VRM アドオン・MakeHuman の素材はユーザーが入れる。`setup.sh` は Python の仮想環境とモデルの取得なので、実行してよいか聞いてから回す）。
2. 入力の頭を、ユーザーと一緒に見て合意する。顔の出来はほぼ入力のモデルで決まる。良くない入力を後の工程で直そうとしない。口が開いている、正面を向いていない頭、髪が頭と一体の 1 部品になっている頭は、作り直してもらう。髪があるなら、髪なしの頭（`HEAD_GLB`）と同じモデルの髪つきの頭（`HAIR_GLB`）の 2 つを用意してもらうのがよい。
3. 作業フォルダ（`work/<名前>/`）に `face.env` を作る（`face.env.example` から）。手順のスクリプトを作業フォルダへコピーしない。人ごとに違うのは `face.env`・`corner_adjust.txt`・承認のファイルだけ。直しや新しい段は `make_face.sh` か `tools/` に入れる。

## 1. 実行と、人の確認（勝手に承認しない）
- `./make_face.sh work/<名前>` は 2〜3 分。2 回、exit 3 で止まる。
- **まぶたの線**（`out/lidfit/check.jpg`、`check_corners.jpg`）と **口の線**（`out/mouthfit/check.jpg`）は、画像をユーザーに見せて、正しいか聞いてから承認する。自分で `md5 -q … > approved` を書いて先へ進まない。数値が合っていても、見た目の線が目の縁・唇の合わせ目に乗っていなければ承認しない。
- 目頭・目尻のずれはユーザーと相談して `corner_adjust.txt`（`目 inner|outer DX DY`、目 0＝画面の左）で、上まぶた全体の高さは `UP_RAISE` で直す。直したら再実行して、新しい確認画像をまた見せる。

## 2. 完成を報告する前に確かめること
「成功」のログだけで完成と言わない。`viewer/`（`python3 -m http.server 5203 --bind 127.0.0.1` → `/viewer/?model=../work/<名前>/<名前>.vrm`）で実際に見て、画像を添えて報告する。

- **入力と同じ人に見えるか**：`out/render_e0/cmp_*.jpg`（上が入力のモデル）。部位ごとの直しを並べる前に、顔全体で同じ人に見えるかを先に言う。一番違う所（たいてい目）を後回しにしない。
- **角度と距離**：正面、斜め、横、後ろ、下から。通常距離と目元・口元の拡大。
- **目**：まぶたの見えている縁が、テクスチャに描かれた開口に乗る。目頭・目尻は尖る。下から見て、まぶたの棚（扇形の灰色の面）が出ない。虹彩・白目の下側にまぶたのピンクや線が写っていない。まつ毛が太い黒帯にならない。
- **閉じ目**：まばたき 1 で目が閉じきる。閉じたまぶたに眉の毛や描かれたまつ毛の筋が出ない。眉が一緒に下がらない（`BLINK_BROW`）。
- **口**：あいうえお、笑顔で、口のキーで鼻が動かない。口角に折れやはみ出しがない。
- **視線**：見る先を上下左右に動かして、目がその方向へ動く（VRM の視線は表情キー方式）。
- **首**：全身なら、首の継ぎ目で顔と体の肌の色が大きく違わない。`HEAD_ONLY=1` なら、横と下から切り口がまっすぐでふたが閉じていて、表情で切り口が動かない（ログ `HEAD_ONLY rim moves … mm` が数 mm 以内）。
- **髪**（髪の部品があるとき）：頭から浮いていない・めり込んでいない、後ろ・上から見て頭皮が透けない、表情やまばたきで髪が崩れない。
- **入力の素材の癖**：上まぶたの棚、眼球に塗られたまぶた、顔に描かれた生え際の線、低ポリの輪郭の角、頂点の少ない頭の焼き付けのモザイク（`BAKE_STEPS=48`）。

## 3. 見た目を直すとき
- 指摘された所だけを変える。変える前に、何をどう変えるかを言って合意を取る。測れるものは前後を測って、数値と画像の両方で報告する。
- 比べるときは、確かめる部位を揃えの基準に使わない（目を比べるなら鼻・口・顎で揃える）。
- 同じ場所を 2 回直してもだめなら、やり方そのものを疑って原因を調べる。

## ファイルの場所
- 出力：`work/<名前>/<名前>.vrm`、`<名前>-closedlid.png/.json`（閉じたまぶたの補正、付属ビューア用）
- 途中：`work/<名前>/out/`（`warped_e0.blend` が合わせた素体、`skin_nolash.png` が肌、`eye_proj.png` が目、書き出し直前は `hair.blend`（髪あり）・`face_only.blend`（髪なし）・`head_only.blend`（`HEAD_ONLY=1`））
- 書き出しだけやり直す：`cd tools/mpfb && NO_HAIR=1 LOOKAT_EXPR=1 VRM_NAME=<名前> ROUGHNESS=<out>/roughness_4k.png "$BLENDER" --background <書き出し直前の blend> --python export_vrm.py -- <出力.vrm>`（`NO_HAIR` は素体のポニーテールを外すもので、移植した髪は残る）
